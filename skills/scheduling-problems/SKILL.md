# 일정·시간표·교대형

## 모델로 옮기기

- **시간 축**: 기준일 0시부터의 정수 분. 칸(slot)은 [시작, 종료). 종료 ≤ 시작이면 다음 날(+1440).
- **기준일 귀속**: 자정을 넘는 칸이 어느 날의 계획에 속하는지(시작일 기준이 흔함). 데이터의 날짜 열이 무엇의 날짜인지 설명서를 읽고 담당자 확인.
- **대상**: 일정에 놓일 것(사람의 근무, 수업, 작업). 길이, 가능 시간대, 필요 자원.
- **자원**: 동시에 하나만 쓸 수 있는 것(사람, 방, 설비). 같은 자원의 칸끼리 겹치면 안 됨.
- **시간 제약 종류**
  - 겹침 금지, 최소 휴식(앞 칸 종료 ~ 다음 칸 시작 ≥ H)
  - 기간 내 최대·최소 횟수(주당 N회), 연속 제한(연속 K일 이하)
  - 선후 관계(A 종료 후 B 시작), 시간창(이 시각 사이에 시작)
  - 기준 시각 대비 여유(예: 시작 X분 전까지 도착, 종료 Y분 후 이후 출발)

## 구성 휴리스틱

1. **가장 제약 많은 것 먼저**: 가능한 칸이 적은 대상, 긴 대상, 선후 관계 앞쪽부터.
2. 각 대상을 **가장 이른(또는 가장 선호되는) 실행 가능 칸**에 놓는다. 자원별로 "점유 구간 목록"을 정렬 유지해 겹침을 빠르게 검사.
3. 교대 편성(날짜 × 근무조 × 필요 인원)은 사실상 **배정형**: 칸 = (날짜, 근무조, 필요 역할), 충돌 = 같은 날 중복·휴식·주간 횟수. `assignment-problems`의 구성·수리·개선을 그대로 쓴다.
4. 시간을 정해야 하는 작업 일정은 **리스트 스케줄링**: 준비된 작업 중 우선순위(마감 빠른 순, 여유 적은 순)대로 가장 이른 가능 시각에.

## 개선

- 한 대상을 다른 칸으로 이동, 두 대상의 칸 교환. 매 이동 후 해당 자원의 겹침·휴식·횟수만 다시 검사(전체 재검사 금지).
- 목적 튜플: (하드 위반, 미배치 수, 품질 위반, 비용·대기 합, 공정성 편차).
- 공정성 대상 예: 야간·주말·기피 칸 횟수의 사람 간 편차.

## 함정

- 근무조·시간대 정의가 기본표와 날짜별 기록에서 다를 수 있다 → 날짜별 기록 우선 여부 확인.
- 주말·휴일 행이 섞여 있을 수 있다(평일 계획이라면 제외 + 경고).
- 계획 기간 선택 시 경계(기간 첫날 전날 밤 칸이 첫날 오전 휴식에 영향).
- 표시용 시각은 날짜 넘김을 보여 준다(예: `06:10(+1)`).

## 출력·검증 포인트

- 배치 목록(대상, 자원, 시작, 종료, 기준일).
- 검증기: 자원별 겹침, 휴식, 기간 횟수, 연속 제한, 시간창, 선후 관계, 기준 시각 여유, 대상 중복·누락.
- 지표: 배치율, 대기 합, 자원 이용률, 공정성 편차, 품질 위반 건수.
- 화면: 자원별 타임라인(간트) — `visual-views`.
