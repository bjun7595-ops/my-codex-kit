# 배포 준비 (요구가 있을 때만)

킥오프에서 요구사항 매트릭스에 배포 항목이 **있을 때만** 진행한다. 있으면 우선순위를 "필수 기능" 수준으로 올린다.

## 항목별 확인

| 요구 | 확인 방법 |
|---|---|
| 비밀값·설정값 환경변수 | 코드에서 비밀번호·DB 주소·포트·시크릿 문자열 검색 → 설정 모듈로 이동. 필수값 없으면 기동 실패(조용한 기본값 금지) |
| 예시 환경 파일 | 모든 키와 **예시값만**. 실제 `.env`는 git 제외 |
| DB 영속성 | 서버 종료 → 재기동 → 현재 데이터셋·결과 그대로 |
| 빈 DB 초기화 | DB 파일 삭제 후 기동 → 테이블·초기 계정·초기 데이터 자동 준비 |
| 헬스체크 | DB 연결까지 확인하는 엔드포인트, 실패 시 503 |
| 컨테이너 파일 | 빌드 → 실행 → 헬스체크 → 재시작 후 유지(볼륨) |

## 컨테이너 파일 단골 실수

- 앱이 `127.0.0.1`에 바인딩 → 컨테이너 밖에서 접속 불가. `0.0.0.0`.
- 데이터 폴더를 이미지에 복사하지 않음 / 경로가 로컬 기준.
- SQLite 경로가 볼륨 밖 → 재시작 시 소실.
- 의존성 목록 누락(개발 중 설치한 패키지).
- 이미지에 `.env`, 임시 폴더, git 폴더 포함 → 제외 목록 파일 작성.
- 비루트 사용자로 실행하면 데이터 폴더 쓰기 권한.

응시 환경에서 컨테이너 빌드가 불가능하면, 파일을 작성하고 "빌드 명령과 확인 절차"를 실행 안내에 적은 뒤 그 사실을 기록한다.
