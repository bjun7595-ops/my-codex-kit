# 시각화

## 좌표 그래프 (지도 없이)

- 위경도를 그대로 x,y로 쓰면 동서가 눌린다 → x = 경도 × cos(평균 위도), y = −위도 로 바꾼 뒤 화면 크기에 맞게 균일 축척(가로·세로 같은 배율) + 여백.
- SVG로 그린다: 노드(종류별 모양: 거점 사각형, 일반 지점 원, 이용자 위치 별), 간선(연속 방문 쌍, 화살표로 방향), 간선 라벨(지정된 소요·거리 값).
- 여러 경로는 순환 팔레트로 색 구분 + 범례(ID·적재). 많으면 선택한 경로만 진하게, 나머지 흐리게.
- 라벨이 겹치면 노드 이름은 hover(title)로.
- 이용자 화면: 내 경로만 + 내 위치와 내 지점을 점선으로, "직선 0.6km" 라벨.

## 타임라인 (일정·교대형)

- 행 = 자원(사람·방·설비), 가로축 = 시간. 막대 = 배치 구간. 자정 넘김은 다음 날로 이어 그린다.
- 위반·경고가 있는 막대는 테두리 강조, hover에 사유.
- 날짜·자원 필터, 오늘·현재 시각 세로선.

## 현재 위치·진행 상태 (시간표 기준 보간)

- 정차·이벤트 목록 [(노드, 시각)]과 현재 시각(같은 기준의 분)으로:
  - 첫 시각 전 → "시작 전, ○분 후 출발"
  - 두 시각 사이 → 진행 중, 비율 = (현재 − 앞 시각) / (뒤 시각 − 앞 시각), 화면 위치 = 두 노드 좌표의 선형 보간
  - 마지막 시각 후 → "완료"
  - 정차 시간이 있으면 도착·출발을 나눠 "정차 중" 상태도
- 현재 시각 기본값은 실제 시각. 시연용 시각 지정 슬라이더는 선택(지시문이 실제 시각 기준이라고 하면 기본값 유지).
- 기준일과 실제 날짜 변환에서 자정 넘김(+1440) 주의.
- 30초 정도 간격으로 갱신.

## 거리 표시

- 좌표만 있으면 하버사인 직선거리(지구 반지름 6371km). 지도가 없으니 **"직선"임을 라벨에 명시**.
- "다음 지점까지 거리"가 이동체 기준인지 이용자 기준인지 모호하면 둘 다 보여 주고 라벨로 구분, 담당자 확인.
- 남은 시간은 거리 추정이 아니라 **시간표 값**(다음 시각 − 현재)으로.

## 표

- 결과 표는 정렬·필터 가능하게(간단한 JS로 충분). 지표 요약 카드 + 시나리오 비교 표.
