# 필수 조건 점검

## 순서

1. README.md와 과제 안내 문서에서 필수 조건과 제출물(파일명 포함)을 빠짐없이 뽑는다.
2. 조건마다 실제 근거를 찾는다.
   - 코드: 어느 파일의 어느 부분이 이 조건을 처리하는지
   - 실행: 테스트나 명령을 실제로 돌린 결과
3. 근거를 직접 확인한 것만 충족으로 표시한다. 코드만 있고 실행해 보지 않았으면 "확인 필요"로 둔다.
4. 아래 형식의 표로 정리한다.

| # | 필수 조건 | 상태 | 근거 (파일 / 실행 결과) |
|---|---|---|---|
| 1 | ... | ✅ 충족 / ⚠️ 확인 필요 / ❌ 미충족 | ... |

5. 표 아래에 미충족·확인 필요 항목을 고칠 순서대로 적는다. 새 기능 추가보다 미충족 조건 해결을 우선한다.

## 주의
- 점검만 하고, 수정은 사용자가 요청할 때 한다.
- 제출물 파일명과 위치가 과제 안내와 정확히 같은지 꼭 확인한다.
